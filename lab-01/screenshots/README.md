# Lab 01 Screenshots

Save your lab verification screenshots in this folder with the following names:

1. `01-http-server.png` - HTTP Server terminal running & browser / curl output showing `"Hello"`.
2. `02-express-welcome.png` - Express Server `GET /` output showing the welcome text.
3. `03-express-about.png` - Express Server `GET /about` output showing JSON with name & section.
4. `04-express-time.png` - Express Server `GET /time` output showing current date and time.
5. `05-express-404.png` - Express Server `GET /unknown-route` showing the 404 error message.

You can capture screenshots using:
- **Windows**: Press `Win + Shift + S` (Snipping Tool).
- Save the cropped screenshots into this `screenshots/` directory.
